## Preservation and provenance

This identified package preserves the files already publicly available at [TestsV-V-3BAC](https://anonymous.4open.science/r/TestsV-V-3BAC/), retrieved on 12 October 2026. All original bytes and relative paths are retained under `original-public-snapshot/`. See `MANIFEST.csv` for SHA-256 hashes and `PROVENANCE.json` for the source ZIP hash. Tests and historical reports were not edited or rerun.

The package is available in this repository as `replication-package.zip`. Repository documentation and the ZIP describe the same preserved snapshot. No peer reviews, private comments, private spreadsheets, or manuscript source files are included.

## Contents and evidence limits

The original directories contain Python and Java test sources labeled by generator. Python directories also include generated bytecode caches and pytest configuration. Two Python generation reports and two Java coverage notes are retained unchanged.

Static inspection found identical generation reports in the Python Codex and DeepSeek directories. Both report 62 cases, 7.15 seconds total, and a validation message of `62 passed in 0.98s`. These messages are historical report contents, not executions independently verified in this preservation work. The Java notes are placeholders saying coverage will be filled after execution. Complete coverage/mutation sessions, project commit identifiers, environment lockfiles, and generation/repair interaction logs are absent from this snapshot. Directory names do not independently authenticate a model or an experiment configuration. See `PUBLIC_SNAPSHOT_OBSERVATIONS.json` for inspectable static observations.

The package supports inspection and preservation of the available tests. It does not, by itself, reconstruct all experimental measurements. Missing provenance, model identities, retries, repair decisions, timing boundaries, and outcome categories need reconciliation with existing author records. No historical selection or execution decisions have been reconstructed.

## Using the files
